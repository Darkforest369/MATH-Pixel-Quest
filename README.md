# Math Pixel Quest

A small pixel-art walking prototype built with Phaser 3. Walk a bordered map. Nothing else is in this first build — no combat, enemies, or doors — so the scene stays easy to extend.

All graphics are generated at runtime with Phaser Graphics. No external image, audio, or font files are required.

## Run locally

From the repository root:

```bash
python3 -m http.server 8000
